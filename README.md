# Livio Acerbo Personal Site

This repository contains the source for a personal landing page styled with a Netflix-inspired theme.

## Features
- Responsive single-page layout using plain HTML, CSS and JavaScript
- "Latest Content" section that fetches and sorts articles from multiple RSS feeds
- Scroll-triggered animations and interactive call-to-action elements

## Usage
No build steps are required. Open `index.html` in your browser or serve it with any static file server.
